# Jira Story Creator Skill

Use this skill to transform project requirements into a clear Jira user story and supporting acceptance criteria.

## Workflow
1. Read the provided requirements or notes.
2. Draft a concise story summary and description.
3. Add acceptance criteria that are testable and specific.
4. Include any assumptions, risks, or dependencies.
5. Keep the story small enough to be actionable.

## Output
- Story summary
- Description
- Acceptance criteria
- Open questions
