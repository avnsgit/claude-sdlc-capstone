# Confluence Page Tree and Documentation Standards

## 1. Page Tree Structure
All documentation created during the SDLC pipeline must be nested under a master root parent page inside the Confluence space defined by `CONFLUENCE_SPACE_KEY`.

```text
[PROJECT] Automated Documentation Sync Pipeline
├── 01-Requirements Spec
├── 02-System Architecture
├── 03-Design Review Findings
└── 04-Implementation Plan
```
